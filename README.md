# WebAppSecurity

This project is based on the original **MR-Robot e-commerce application**:

https://github.com/MarianCristianStan/Mister-Robot

The repository is structured around two branches:

- `insecure-implementation` — contains intentionally vulnerable implementations
- `secured-implementation` — contains the secured/fixed versions of the same features

The project was used as a practical environment to test and demonstrate common web security vulnerabilities such as **SQL Injection, Cross-Site Scripting (XSS), and Session Hijacking**, as well as the corresponding mitigation techniques.

The goal is to compare insecure and secure implementations of the same application features in a controlled environment.
